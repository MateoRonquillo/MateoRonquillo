`LoRaWAN` · `ESP32-S3` · `SX1262` · `FUOTA` · `OMNeT++` · `INET` · `Python`

**Focus**

- 📦 Firmware fragmentation
- 📡 Multicast distribution
- 🔐 Firmware integrity
- 🔑 SHA-256 verification
- ⚡ Efficient firmware transmission
- 🧪 Network simulation
- 📊 Performance evaluation

The project explores a hybrid approach combining **physical experimentation and network simulation** to evaluate firmware-update strategies for constrained LoRaWAN devices.

# 📈 My Development Philosophy

> **Understand the system. Measure the problem. Automate the solution.**

I try to approach software development through three principles:

### 🔍 Understand

Before optimizing a system, understand its architecture, dependencies and constraints.

### ⚙️ Automate

If something needs to be repeated, it should probably be automated.

### 🚀 Optimize

Prefer solutions that improve reliability, maintainability and efficiency rather than simply adding complexity.
